# 型番商品確認くん

型番や、よく見るランキングページのURLをまとめて置いておくための静的Webツール。
ビルド不要、GitHub Pages にそのまま置ける。

## 構成

```
index.html          画面
app.js              ロジック
style.css           スタイル
logo.png / favicon.png
data/products.json  データ本体（GitHubに保存される）
SETUP.md            セットアップ手順
```

## グローバルメニュー

| タブ | 中身 |
|---|---|
| 📊 amazonランキング | 攻めで見るジャンル。Amazon URL → 楽天 URL の並び |
| 🏆 楽天ランキング | 守りで見るジャンル。楽天 URL → Amazon URL の並び |
| 🥊 楽天ライバル | 見て回るライバル店。**強さ / ショップ名 / 楽天 URL** だけの身軽な形 |
| 📦 追加した商品 | オフェンス／ディフェンスで追加した商品を、**追加日ごと**にまとめて表示する |

データ形式は4タブ共通で、保存は「💾 保存」1回で `data/products.json` に全部入る。
違うのはURL欄だけ。

| | amazonランキング | 楽天ランキング |
|---|---|---|
| 1列目 | 並び（↑↓） | 並び（↑↓） |
| 2列目 | 区分（amazonランキング＝青） | 区分（楽天ランキング＝緑） |
| 大カテゴリ | ✕（使わない） | ✕（使わない） |
| URL欄 | Amazon URL / 楽天 URL | 楽天 URL / Amazon URL |

同じジャンルのAmazon側と楽天側を1行にまとめて持てる。どちらを基準に見るかでタブを分けていて、
一覧表も編集モーダルも、そのタブの基準側のURLが先に並ぶ。名称のリンク先も基準側のURL。

**区分の付け替えでタブを移動できる。** 表の1列目（画像の左）と編集モーダルの「区分」は同じ
ドロップダウンで、**amazonランキング（青）／楽天ランキング（緑）／楽天ライバル（紫）** を選び直すとその行が別のタブへ移る（2段表記）。
データ形式は2タブ共通なので、URL・確認内容・確認日・商品リストはそのまま引き継がれる。
移動後は移した先のタブが開く。

## 🥊 楽天ライバル

巡回リストの仲間だが、ライバル店を仕分けるために少し形が違う。

| | 中身 |
|---|---|
| **強さ** | カテゴリー名の位置。**未設定 / 弱小 / 中堅 / 競合** から選ぶドロップダウン（選んだ瞬間に保存） |
| **ショップ名** | ジャンル名の位置。名称のリンク先は楽天URL |
| **楽天 URL** | Amazon URL は出さない |
| 確認内容 | 出さない |

- 上部の絞り込みボタンも **弱小 / 中堅 / 競合** になる。「強さ」の見出しを押すと、その順（弱小→中堅→競合）で並ぶ
- 帯の数え方は「ショップ」、検索は「ショップ名・URLで検索…」
- 区分を「ディフェンス」などに付け替えれば、これまで通り他のタブへ移せる。
  **見えていない Amazon URL や確認内容も、そのまま持ったまま移る**

## 📦 追加した商品

オフェンス／ディフェンスの各行で「＋ 商品」から入れた商品が、**全タブ横断で追加日ごとに縦に並ぶ**タブ。
いろんなランキングからまとめて放り込んでおいて、あとから新しい順に確認していくための場所。

- 追加日の新しい順。日付ごとに `2026-08-20 [今日] 3件` の見出しが入る
- 列は **出所 / amazon画像 / 楽天画像 / 商品名 / amazonURL / 楽天URL / 30日販売数 / 隙あり/なし / 楽天ライバル状況 / 商品品質 / 買付 / 操作**
- 両モールが並ぶ。片側しか無い商品も、「編集」でもう片方のURLを足せる。足すと画像は裏で自動取得される
  （v0.59.0から「チェックした商品」の表も同じ顔ぶれになった）
- **30日販売数**は自由入力。欄に直接書けて、離れた時点で保存される
- **楽天ライバル状況**はドロップダウン。既定は **未調査**（灰） / **少数**（青） / **そこそこいる**（黄） / **激戦**（赤）。選んだ瞬間に保存される
- **商品品質**もドロップダウン。既定は **未調査**（灰） / **4.0以下**（黄） / **4.0以上**（緑）
- 楽天ライバル状況 / 商品品質 / 隙あり/なし / 買付 の選択肢は ⚙️設定の「🏷 ラベル」または ▦列管理の「項目管理」で
  文言・色・増減・並べ替えができる。**項目そのものを増やす・消すのは ▦列管理の「項目管理」**
  （消した項目の列は表から無くなる。商品に付いていた値は消さずに残す）
- **出所は2行**。1行目に区分バッジ（amazonランキング＝青 / 楽天ランキング＝緑 / 楽天ライバル＝紫）、2行目に
  ジャンル名が出る。ジャンル名を押すとそのランキングページが開く
- **出所のジャンル名は `>` では改行しない**（v0.96.0）。1行で出て、長ければ普通に折り返す。
  **途中で切らずに全部出す**（v0.91.0）ので、折り返した行はその行だけ縦に伸びる。
  ジャンル名が空の行は「—」（一覧の列は今まで通り `>` で改行する）
- 確認 / 買付 のドロップダウン、編集、削除はここから直接できる。元のタブにもそのまま反映される
- **編集は「操作」列の中**（オレンジの「編集」＋赤い「✕」）。他の表と同じ並びで、専用の「編集」列は無い（v0.87.0）
- 上部のボタンで出所（タブごと）を絞り込める。検索は商品名・URL・出所が対象
- ここでは新規追加できない（商品は各ランキング行の「＋ 商品」から入れる）

## ⚙️ 設定

3つのタブに分かれている。

| タブ | 中身 |
|---|---|
| 💾 保存先 | オーナー / リポジトリ / ブランチ / Personal Access Token、自動保存の切り替え、読み込み・接続テスト |
| 📷 商品画像 | 楽天のアプリID・アクセスキー、Amazonのアソシエイトタグ、中継サービス（折りたたみ）、取得テスト |
| 🏷 ラベル | 商品行のドロップダウン（楽天ライバル状況 / 商品品質 / 隙あり/なし / 買付）の選択肢 |
| ↩ 復元 | 履歴から復元 |

**ラベルタブ** — 表と同じ並び（楽天ライバル状況 → 商品品質 → 隙あり/なし → 買付）で、各ドロップダウンの選択肢を編集できる。
グループの見出しは「▦ 列管理」で付けた項目名に追従する（「楽天ライバル状況」を「ライバル」に変えれば、ここも「ライバル」になる）。

- **表示名**を書き換えられる。**色**は8色（グレー / 青 / 緑 / 黄 / 赤 / 紫 / 青緑 / ピンク）から選ぶ。右端に現物のプレビューが出る
- **＋ 選択肢を追加** で項目を増やせる。**✕** で削除、**↑ ↓** で並べ替え
- 使用中の選択肢を削除しようとすると、何件付いているかを確認したうえで、その商品を先頭の選択肢に付け替える。値が宙に浮くことはない
- 選択肢は1つ以上必要（最後の1つは削除できない）
- 表示名を変えても内部の値は変わらないので、既存データはそのまま
- 設定は `data/products.json` の `labels` に入るので全端末で共通。「既定に戻す」でいつでも元に戻せる

伏せ字の欄（PAT・楽天アクセスキー）は右端の「表示 / 隠す」で切り替えられる。開き直すと必ず伏せ字に戻る。

## ⚙️ 履歴から復元

⚙️設定の「履歴から復元」で、`data/products.json` のコミット履歴を古い順に全部読み込んで、
**途中で消えた行や商品を拾い集めて1つにまとめる**。端末をまたいだ上書きなどで取りこぼしたものを戻すための機能。

- 直近◯版（既定30）を指定して「履歴を読み込んで統合」
- 各版の日時・行数・商品数が一覧で出るので、どこで減ったか目で追える
- ランキング行は `id`、商品は `URL` で同じものと判断して重複させない
- 名称・確認内容などのスカラ値は**新しい版**を、商品の集合は**全版の和**を採る。追加日は最初に入れた日を残す
- 壊れた画像URL（2本連結してしまったもの、サービスの既定ロゴ、`no-image` 等）はここで直す・捨てる
- **読み込んだだけではGitHubに書き込まない。** 画面に反映して中身を確かめてから「💾 保存」を押す

## ウィンドウを2つ開く

ロゴの右の **⧉ 新しいウィンドウ** で、同じ画面をもう1つ開ける。
巡回リストを左、作業リストを右、のように並べて使える。

同じブラウザで開いた窓どうしは**中身が自動で揃う**。片方で編集すると、もう片方にもすぐ反映される
（編集モーダルを開いている間やインライン編集中は割り込まないので、入力が消えることはない）。

## 見た目で役割を分けている

4つのタブは役割が違うので、色と情報の出し方を変えている。

| | 役割 | 色 |
|---|---|---|
| 📊 amazonランキング | **巡回リスト** — 決まったランキングを見て回り、商品を拾う | 青 |
| 🏆 楽天ランキング | **巡回リスト** — 同上（楽天側が起点） | 青 |
| 🥊 楽天ライバル | **巡回リスト** — 同上（ライバルのページを見て回る） | 青 |
| 📦 追加した商品 | **作業リスト** — 拾った商品を上から順に処理する | 緑 |

巡回リストの3つは同じ役割なので同じ青。作業リストは緑。どのタブの行かは「区分」列のバッジ（青／緑／紫）で見分ける。

- タブの色・表の見出し・帯・日付の見出しが、開いているタブの色に切り替わる
- タブの下の**帯**に、そのタブでいま知りたいことを出す
  - 巡回リスト：ジャンル数 / 拾った商品数 / **14日以上みてない** ジャンルの数 + 役割の説明
  - 作業リスト：今日の件数 / 全件数 + **隙あり/なし・買付の状態ごとの件数**（ラベルの色そのまま）
- 作業リストの各行は、左端に**隙あり/なしの色帯**が付く
- **選択肢の色は7つ**（v0.97.0）… グレー / 青・薄い青 / 赤・薄い赤 / 緑・薄い緑
- **行の背景は選択肢の色で決まる**（v0.97.0）。項目は全部見る（楽天ライバル状況・商品品質・隙あり/なし・買付…）
  - **赤系（赤・薄い赤）が1つでも付いていたら → 赤**（激戦・売れそうにない など）
  - 赤系が無くて **青系（青・薄い青）が付いていたら → 青**（買付済・倒せそう など）
  - どちらも無ければ **白**（グレーと緑は行の色に影響しない）
  - 色は ⚙設定の🏷ラベル、または ▦列管理 の「項目管理」でいつでも変えられる
  - この色は **amazonランキング / 楽天ランキング / 楽天ライバル の「チェックした商品」でも同じように出る**
  - 「項目管理」で増やした項目の赤でも同じように効く

## できること

- 一覧は普通の表。並び / 区分 / アイキャッチ画像 / 楽天ジャンル名 / amazonジャンル名 / URL（基準側が先） / 確認内容 / 確認日 / 商品数 / 商品追加 / 操作
- **ジャンル名は折り返して表示される**。行の高さに収まる行数まで出て、それ以上は省略される（「▦ 列管理」で行の高さを上げれば、その分たくさん出る）
- **ランキング2タブにカテゴリー名は無い**（v0.76.0で外した）。楽天ライバルの「強さ」だけがこの位置に残る
- 列見出しクリックで昇順↔降順の並べ替え
- **新しく登録した行は、並べ替えの指定にかかわらず表の一番上に出る**。左端に青い線が入り、追加直後は薄く光る。列見出しを押して並べ替え直すか、↑↓ で手を入れると固定は解けて通常の並びに戻る（次に開いたときも通常の並び）
- 「チェックした商品」も、同じ追加日の中では**あとから入れたものが上**に来る
- 一番左の **並び** 列の **↑ / ↓** で行を1つずつ動かせる。押した時点で「手動の並び」に切り替わり、その順序は `data/products.json` に保存される（端末をまたいでも同じ順）。見出しの **並び** をクリックすると自動並べ替えに戻り、もう一度押すと今見えている順で手動に固定できる。タブごとに別々に持てる
- **✎ 表編集** を押すと、表の中で名称・カテゴリ・URL・確認内容・画像URLを直接書き換えられる（入力欄から離れた時点で保存。行の削除もここから）
- 上部の **▦ 列管理** を押すと、**画面の下半分にパネルが出る**（上端は必ずモニターの真ん中より下）。
  上のタブで何をいじるか選ぶ。**■項目管理**：ドロップダウンの項目そのもの。
  **「＋ 項目」で項目を増やせて、「この項目を削除」で消せる**。中の選択肢（文言・色・増減・並べ替え）も
  ここで編集する（⚙️設定の🏷ラベルと同じ中身）。項目名は列管理の項目名と同じもので、どちらから変えても揃う。**■ランキング**：amazonランキング / 楽天ランキング / 楽天ライバル / 追加した商品、
  **■展開部分**：その3タブそれぞれの「チェックした商品」）。開いたときはいま見ているタブの表が選ばれる（●が付いている方）。
  後ろは暗くならず、**開いたまま表をスクロールしたり触ったりできる**ので、実物を見ながら直せる。
  閉じるのは ✕ / 「閉じる」 / Esc（後ろをクリックしても閉じない）。**3つの表をまとめて設定できる**ので、
  どのタブからでも全部いじれる（いま開いている表が先頭に来て「いま開いている表」と付く）
  - **amazonランキング** / **楽天ランキング** / **楽天ライバル** / **追加した商品** … 表ごとに独立
  - **チェックした商品** … 一覧の行を「N件表示」で開いた表
  - **追加した商品** … 「追加した商品」タブの表
  変えられるのは **どの列を出すか / 並び順 / 項目名 / 幅（px） / 揃え（左・中央・右）**。行の高さもここで指定する
  - **列が1行ずつ縦に並ぶ。** 左から **↑↓ / ☑表示 / 項目名 / 幅 / 揃え**
  - **☑** を外すとその列が消える。隠した行は薄くなり項目名に取り消し線が入る。「全部表示」でまとめて戻せる。最後の1列は隠せない
  - **項目名はどの表でも共通。** 同じものを指す列（商品名 / 隙あり/なし / 買付 / 操作 / 画像 / URL / 30日販売数 / ライバル状況 / 品質）は、
    「追加した商品」で名前を変えれば「チェックした商品」も一緒に変わる（モーダル内の相手側の欄もその場で追従する）
  - **幅と揃えは表ごと。** 同じ「amazon画像」でも、追加した商品では広く・チェックした商品では狭く、が普通にできる
  - **表示/非表示も表ごと。** 「追加した商品」で楽天画像を隠しても、楽天ランキングタブの「チェックした商品」の楽天画像は消えない
  - **並び順は ↑↓ で1つずつ動かす**（端では押せなくなる）
  - 変更はその場で表に反映される（保存ボタンは要らない）
  - 設定は7つのまとまりで持つ。**巡回3タブ**・**追加した商品**・**3タブそれぞれのチェックした商品**、すべて独立
  - 巡回リストの **URL列だけは、そのタブの基準側が必ず先**
  - 揃えは見出しだけでなく**セルの中身にも効く**。文字はもちろん、入力欄の中の文字、画像の位置、確認日のような塊も一緒に寄る
  - 揃えは同じボタンをもう一度押すと既定に戻る。幅は空欄で既定、列の境目をドラッグしても変えられる（境目のダブルクリックで既定）
  - 「既定に戻す」で全部リセット
  - 設定は `data/products.json` の `cols` に入るので**全端末で同じ見た目**になる（v0.45以前にブラウザへ保存していた列幅は、初回に自動で移行される）
- **URL欄は「文字 / URL」を選べる。** URLではなく覚え書きを書きたいときは **文字** にすると、
  リンクにせずそのまま文字として出る（入力欄も文字用に変わる）。既定は **URL**
  - **切り替えボタンは編集するところにだけ出る。** 一覧の表には出さない
    （行の「編集」で開くモーダルのURL欄の見出しの右、商品行の「編集」を押したときのURL欄の下）
  - 切り替えは欄ごと・行ごとに覚える（`data/products.json` の `modes` に入る）
  - **文字**にした欄は「唯一 / 他あり」の判定からも外れる
- **URLの下に「唯一」／「他あり N」が小さく出る。** 同じURLを他の行や商品にも入れていないかの目印
  （押せない飾り。マウスを乗せると「同じURLが他に◯件あります」と出る）
  - 一覧表のURL列・「チェックした商品」・「追加した商品」の全部に出る
  - **Amazonは ASIN が同じなら同じURL扱い**（`?th=1` や長い日本語入りのURLでも拾える）。
    それ以外は `www.` と末尾スラッシュと `?` 以降を無視して、ホスト＋パスで見る
- **URLの下に「唯一」／「他あり N」が小さく出る。** 同じURLを他の行や商品にも入れていないかの目印
  （押せない飾り。マウスを乗せると「同じURLが他に◯件あります」と出る）
  - 一覧表のURL列・「チェックした商品」・「追加した商品」の全部に出る
  - **Amazonは ASIN が同じなら同じURL扱い**（`?th=1` や長い日本語入りのURLでも拾える）。
    それ以外は `www.` と末尾スラッシュと `?` 以降を無視して、ホスト＋パスで見る
- 表は画面幅いっぱい。横スクロールバーは出さず、狭い画面では列幅が比率を保ったまま縮む
- **縦スクロールバーは常に右側に出したまま。** 画面が短くてスクロールが要らないときも帯が出る。
  行が増減するたびに出たり消えたりすると、そのぶん表の幅が変わって、商品を追加した直後に
  列がずれて見えるため
- 確認日は表の中で直接入力でき、**すぐ下の「本日反映」**で今日の日付が入る（横に並べず縦に積むことで列幅を狭くしている）。14日を超えると欄が琥珀色に
- 「商品」列の **N 件表示** で行を展開すると、既存の商品だけが表で並ぶ。
  **列は「追加した商品」タブと同じ顔ぶれ**（出所だけはその行そのものなので無い）:
  **追加日 / 商品名 / 両モールの画像・URL / 30日販売数 / 隙あり/なし / 楽天ライバル状況 / 商品品質 / 買付 / 操作**（編集ボタンは「操作」列の中）。
  30日販売数・ライバル状況・品質はここで直接入れられて、「追加した商品」タブにもそのまま出る
  - **画像とURLは、開いているタブのモールが先**（amazonランキングなら `amazon画像`→`amazonURL`→`楽天画像`→`楽天URL`、楽天ランキング・楽天ライバルは逆）
  - 要らない列は **▦ 列管理** の「チェックした商品」で隠せる（隠しても「追加した商品」タブ側は消えない）
  - 「＋ 商品」の入力行でも**両モールのURLと30日販売数**をまとめて入れられる。基準側だけ入れてもよい
- **画像をクリックすると拡大表示**。AmazonやRakutenのサムネURLは大きいサイズに組み立て直してから出す。商品名と「商品ページを開く」リンクも一緒に出る。Esc・背景クリック・✕で閉じる。一覧のアイキャッチ画像も同じように開ける
- 状態のドロップダウン（区分 / 楽天ライバル状況 / 商品品質 / 隙あり/なし / 買付）は、**開いた一覧の各行にも設定した色が付く**。
  `<select>` だと展開時の色がブラウザ任せになるため、自前で描いている。Esc・外側クリックで閉じる
- 商品行の右には状態のドロップダウンが2つ。**隙あり/なし**（未判定 / 隙あり / 隙なし）と **買付**（買付前 / 買付済 / スキップ）。選んだ瞬間に保存される
- 「商品追加」列の **＋ 商品** を押すと、表の1行目に空の入力行が現れてURL欄にカーソルが入る。Enter（または「追加」）で積み上がり、また空行に戻るので連続投入できる
  - 入力行を出している間は、同じ緑の **＋ 商品** が赤い **✕ キャンセル** に変わる。押すと**入力行と、その下に開いた「チェックした商品」ごと閉じる**
- **「N 件表示」ボタンは、中の商品の色で塗り分かれる**（v0.97.0）。色は行の背景と同じ
  白 / 青 / 赤。混ざっていれば等分の帯になる（3種類＝33%ずつ、2種類＝50%ずつ）。
  **0件の行と、全部白の行は白**。混ざっているときはマウスを乗せると
  「白 1 / 青 1 / 赤 1」と内訳が出る。
  開いている間は表そのものが見えるので、ボタンは今まで通りの青
- 商品テーブル右上の **✕ 閉じる** で、その行の商品欄をたたむ
- 商品行の **操作列の「編集」**（オレンジ）でその場で編集。押すと行が入力欄になり、同じ位置が緑の **保存** ＋ **↩** に変わる（Enterで保存、Escでやめる）
- 編集モーダルは左にアイキャッチ画像、右に各項目（上段に 区分 / カテゴリー名 / 最終確認日、その下に ジャンル名 → URL → 確認内容）、下に追加済みの商品一覧
- **ジャンル名は `>` のところで改行して見せる。** `キッズ・ベビー・マタニティ > ベビーファッション > …` は
  1段ずつ縦に並ぶ。何段まで見えるかは行の高さ次第（▦ 列管理 の「行の高さ」を上げれば全部出る）
- **ジャンル名はモールごとに2つ持つ。** 楽天URLからは **楽天ジャンル名**、Amazon URLからは **amazonジャンル名**。
  編集モーダルは **URL → そのモールのジャンル名** の順に並ぶ（基準側のモールが先）
- **amazonジャンル名は日本語で取る**（v0.95.0）。中継サービス越しだとAmazonが英語のページを返すことが
  あるので、日本語を明示して取りに行く。それでも英語で返ってきたときは別の中継を試し、
  どれも英語ならそのまま入れる（空にはしない）。うまく取れないときは ⚙設定 の画像取得テストに
  そのURLを入れると、どこで英語になったかログが出る
- **URLを入れると、そのモールのジャンル名が自動で入る。**（amazonランキング / 楽天ランキングの2タブ）
  ページを中継サービス越しに読んで、**パンくず**から `家電 > 扇風機・サーキュレーター` の形に組み立てる
  （Amazonは `wayfinding-breadcrumbs` を見る。取れないときはタイトルから）
  - **入るのはジャンル名が空のときだけ。**入っている名前を勝手に書き換えることはない
  - 編集モーダルの「楽天URLから取得」「Amazon URLから取得」を押せば、いつでも取り直せる（上書きされる）
  - 表の中で楽天URLを直接書き換えたときも、名称が空なら裏で取りにいく
  - 拾う順は **構造化データ（BreadcrumbList） → ページのパンくず → 見出し・タイトル**。
    「楽天市場トップ」「ランキングトップ」のような毎回同じものは捨てる
  - **中継サービスが混んでいると取れないことがある。** そのときは何もしないので、手で書けばよい。
    ⚙️設定の「画像取得テスト」に楽天URLを入れると、どの中継でどう失敗したかが出る
- **商品URLを入れるだけで画像が自動で入る**。「チェックした商品」に商品URLを入れて追加/編集すると、追加自体はその場で完了して、画像は裏で取りにいく（画像欄が `取得中` になり、取れたらその行だけ差し替わる）。待たされないので、続けて次の商品URLを入れられる。画像欄が空のとき、次の順で拾う
  1. **Amazon** — URL内のASINから、アソシエイトのAsinImageウィジェットと旧来の画像パターンを候補にして、実際に読めたものを採用（⚙️設定にアソシエイトタグを入れると通りやすい）
  2. **楽天** — `item.rakuten.co.jp/{店舗}/{商品番号}/` から itemCode を作り、楽天ウェブサービスの商品検索APIをJSONPで呼ぶ（⚙️設定にアプリID・アクセスキーが要る）
  3. **メタ情報サービス** — microlink にURLを渡して画像URLをもらう
  4. **中継サービス** — ページのHTMLを取って、商品画像や `og:image` / `twitter:image` を拾う（6つを順に試す）。
     Amazonは `hiRes` / `data-old-hires` に加えて、ページ中の `images/I/…` を全部拾い、
     画像IDから大きいサイズのURLを組み立て直して大きい順に試す（サムネやアイコンを掴まないため）

  AmazonのURLは 4 → 3 の順で試す（ページから読むほうが当たるため）。
  どの経路でも、サービス側の既定ロゴ・`no-image`・SVG などは商品画像ではないものとして捨てる

  AmazonのURLは `https://www.amazon.co.jp/dp/{ASIN}` の短い形に直してから照会する。
  画像が入らなかった商品はサムネが `↻` になり、押すともう一度取りにいく（既定で複数の中継先を順に試す。⚙️設定で変更・無効化できる）

  うまく入らないときは ⚙️設定 の **画像取得テスト** に商品URLを入れて「実行」すると、どの段階で止まっているかが出る

  どれも「実際に画像として読めたか」を確認してから採用するので、壊れたURLが入ることはない。手で貼りたいときは今まで通り画像欄に直接URLを入れればよい
- タブごとの検索とカテゴリ絞り込み
- **自動保存**。変更してから約4秒（触り続けていても1分に1回）で `data/products.json` にコミットされる。タブを閉じる・裏に回すときにも保存する。手動の「💾 保存」（`Cmd/Ctrl + S`）も今まで通り使える
  - ヘッダーの表示が `● 未保存（まもなく保存）` → `⟳ 保存中…` → `✓ HH:MM 保存済み` と変わる
  - 失敗したら `⚠ 保存できず` になり、30秒おきに5回まで自動で再試行する。クリックすればその場で再試行
  - 別端末が先に保存していた（409）ときは、最新のshaを取り直して1度だけ自動でやり直す
  - ⚙️設定の「自動保存する」を外せば、これまで通り手動保存だけになる
  - **起動時は必ずGitHubの最新と突き合わせてから保存を解禁する。** この端末のブラウザに残っている
    内容とGitHub側の `updatedAt` を比べて、新しいほうを採用する。突き合わせが終わるまでは
    自動保存も手動保存も走らないので、しばらく開いていなかった端末が他端末の変更を消すことはない
  - GitHub側より件数が半分以下に減る保存は自動では行わない。意図した削除なら「💾 保存」を押すと
    確認のうえで上書きできる

編集内容はブラウザの localStorage にも自動保存されるので、保存し忘れてタブを閉じても復元される
（ヘッダーに `● 未保存` が出ていれば未コミット）。

セットアップは [SETUP.md](SETUP.md) を参照。

## データ形式

```jsonc
{
  "version": 3,
  "updatedAt": "ISO8601",
  "sections": {
    "amazon":   { "items": [ /* 下記の共通形式 */ ] },
    "rakuten":  { "items": [ /* 同上 */ ] },
    "rivals":   { "items": [ /* 同上 */ ] },
    "products": { "items": [ /* 同上 */ ] }
  }
}

// 4タブ共通のアイテム
{
  "id": "itm_xxxx",
  "name": "名称",              // 楽天ジャンル名（商品タブなら商品名）
  "nameAmazon": "amazonジャンル名",
  "url": "https://...",        // 型番商品タブのURL
  "urlAmazon": "https://...",  // Amazon側のURL（巡回タブ共通）
  "urlRakuten": "https://...", // 楽天側のURL（巡回タブ共通）
  "image": "https://…/eye.jpg", // アイキャッチ画像
  "modes": { "urlAmazon": "text" },  // URL欄を文字として扱う指定（既定はURL）
  "category": "カテゴリ",
  "checkNote": "確認内容",
  "checkedAt": "2026-08-19",   // 最終確認日 (YYYY-MM-DD)
  "picks": [                   // 関連URL・チェックした商品
    // st は「項目管理」で増やした項目の値（既定の4つは check / buy / rival / quality のまま）
    { "id": "pk_xxxx", "addedAt": "2026-08-19", "title": "商品名",
      "urlAmazon": "https://...", "imageAmazon": "https://…",
      "urlRakuten": "https://...", "imageRakuten": "https://…",
      "check": "before|after|skip"  // 隙あり/なし, "buy": "before|done|skip",
      "sales30": "328", "rival": "|few|some|heavy", "quality": "|low|high" }
  ],
  "createdAt": "ISO8601",
  "updatedAt": "ISO8601"
}
```

`cols` は列の見た目。**`labels` だけが表をまたいで共通**（`{title:"商品名", st_check:"隙あり/なし", …}`）で、
`layout`（`{rank:{列:{w,align}}, added:{…}, pick:{…}}`）・`order`・`hide` は表ごと。
まとまりは `amazon` / `rakuten` / `rivals` / `added` / `pick_amazon` / `pick_rakuten` / `pick_rivals` の7つ。v0.62.0以前の `items` は読み込み時に自動で移行される。

旧形式（v1の `items` 直下、v2の `model` + `links[]`）は読み込み時に自動で移行される。
型番と商品名は `name` にまとめられ、2本目以降のURLは `picks` に移る。

`links[].type` は `rakuten` / `rakuten_rank` / `amazon` / `amazon_rank` / `yahoo` /
`mercari` / `alibaba` / `taobao` / `official` / `other`。

旧形式（`items` が直下にある v1）のJSONを読み込んだ場合は、自動的に `sections.products` に移行される。
