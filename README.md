# 型番商品確認くん

型番や、よく見るランキングページのURLをまとめて置いておくための静的Webツール。
ビルド不要、GitHub Pages にそのまま置ける。

## 構成

```
index.html          画面
app.js              ロジック
style.css           スタイル
logo.png / favicon.png
data/products.json  データ本体（GitHubに保存される）
SETUP.md            セットアップ手順
```

## グローバルメニュー

| タブ | 中身 |
|---|---|
| 📊 amazon基準（オフェンス） | 攻めで見るジャンル。Amazon URL → 楽天 URL の並び |
| 🏆 楽天基準（ディフェンス） | 守りで見るジャンル。楽天 URL → Amazon URL の並び |
| 📦 追加した商品 | オフェンス／ディフェンスで追加した商品を、**追加日ごと**にまとめて表示する |

データ形式は3タブ共通で、保存は「💾 保存」1回で `data/products.json` に全部入る。
違うのはURL欄だけ。

| | amazon基準（オフェンス） | 楽天基準（ディフェンス） |
|---|---|---|
| 1列目 | 並び（↑↓） | 並び（↑↓） |
| 2列目 | 区分（オフェンス＝青） | 区分（ディフェンス＝緑） |
| 大カテゴリ | ○（ジャンル名の左） | ○（ジャンル名の左） |
| URL欄 | Amazon URL / 楽天 URL | 楽天 URL / Amazon URL |

同じジャンルのAmazon側と楽天側を1行にまとめて持てる。どちらを基準に見るかでタブを分けていて、
一覧表も編集モーダルも、そのタブの基準側のURLが先に並ぶ。名称のリンク先も基準側のURL。

**区分の付け替えでタブを移動できる。** 表の1列目（画像の左）と編集モーダルの「区分」は同じ
ドロップダウンで、**オフェンス（青）／ディフェンス（緑）** を選び直すとその行がもう一方のタブへ移る。
データ形式は2タブ共通なので、URL・確認内容・確認日・商品リストはそのまま引き継がれる。
移動後は移した先のタブが開く。

## 📦 追加した商品

オフェンス／ディフェンスの各行で「＋ 商品」から入れた商品が、**全タブ横断で追加日ごとに縦に並ぶ**タブ。
いろんなランキングからまとめて放り込んでおいて、あとから新しい順に確認していくための場所。

- 追加日の新しい順。日付ごとに `2026-08-20 [今日] 3件` の見出しが入る
- 列は 画像 / 商品名 / 商品URL / **出所** / 確認 / 買付 / 編集 / 操作
- **出所**はどのランキング行から追加したかで、区分バッジ（オフェンス＝青 / ディフェンス＝緑）と
  ジャンル名が出る。ジャンル名を押すとそのランキングページが開く
- 確認 / 買付 のドロップダウン、編集、削除はここから直接できる。元のタブにもそのまま反映される
- 上部のボタンで出所（オフェンス / ディフェンス）を絞り込める。検索は商品名・URL・出所が対象
- ここでは新規追加できない（商品は各ランキング行の「＋ 商品」から入れる）

## ⚙️ 設定

3つのタブに分かれている。

| タブ | 中身 |
|---|---|
| 💾 保存先 | オーナー / リポジトリ / ブランチ / Personal Access Token、自動保存の切り替え、読み込み・接続テスト |
| 📷 商品画像 | 楽天のアプリID・アクセスキー、Amazonのアソシエイトタグ、中継サービス（折りたたみ）、取得テスト |
| ↩ 復元 | 履歴から復元 |

伏せ字の欄（PAT・楽天アクセスキー）は右端の「表示 / 隠す」で切り替えられる。開き直すと必ず伏せ字に戻る。

## ⚙️ 履歴から復元

⚙️設定の「履歴から復元」で、`data/products.json` のコミット履歴を古い順に全部読み込んで、
**途中で消えた行や商品を拾い集めて1つにまとめる**。端末をまたいだ上書きなどで取りこぼしたものを戻すための機能。

- 直近◯版（既定30）を指定して「履歴を読み込んで統合」
- 各版の日時・行数・商品数が一覧で出るので、どこで減ったか目で追える
- ランキング行は `id`、商品は `URL` で同じものと判断して重複させない
- 名称・確認内容などのスカラ値は**新しい版**を、商品の集合は**全版の和**を採る。追加日は最初に入れた日を残す
- 壊れた画像URL（2本連結してしまったもの、サービスの既定ロゴ、`no-image` 等）はここで直す・捨てる
- **読み込んだだけではGitHubに書き込まない。** 画面に反映して中身を確かめてから「💾 保存」を押す

## できること

- 一覧は普通の表。並び / 区分 / アイキャッチ画像 / 大カテゴリ / 名称 / URL（基準側が先） / 確認内容 / 確認日 / 商品数 / 商品追加 / 操作
- **ジャンル名は折り返して表示される**。行の高さに収まる行数まで出て、それ以上は省略される（「⇔ 幅・高さ調整」で行の高さを上げれば、その分たくさん出る）
- **大カテゴリ**はジャンル名の左。上部のボタンで絞り込める。編集モーダルでも入力欄が出て、既に使ったカテゴリが候補に出る
- 列見出しクリックで昇順↔降順の並べ替え
- **新しく登録した行は、並べ替えの指定にかかわらず表の一番上に出る**。左端に青い線が入り、追加直後は薄く光る。列見出しを押して並べ替え直すか、↑↓ で手を入れると固定は解けて通常の並びに戻る（次に開いたときも通常の並び）
- 「チェックした商品」も、同じ追加日の中では**あとから入れたものが上**に来る
- 一番左の **並び** 列の **↑ / ↓** で行を1つずつ動かせる。押した時点で「手動の並び」に切り替わり、その順序は `data/products.json` に保存される（端末をまたいでも同じ順）。見出しの **並び** をクリックすると自動並べ替えに戻り、もう一度押すと今見えている順で手動に固定できる。タブごとに別々に持てる
- **✎ 表編集** を押すと、表の中で名称・カテゴリ・URL・確認内容・画像URLを直接書き換えられる（入力欄から離れた時点で保存。行の削除もここから）
- 上部の **⇔ 幅・高さ調整** で、**一覧表**と**チェックした商品**の2グループに分けて、各列の幅と行の高さをpxで入力できる。一覧表の列幅は境目のドラッグでも変更可（ダブルクリックで既定に戻る）。どちらもブラウザに保存される
- 表は画面幅いっぱい。横スクロールバーは出さず、狭い画面では列幅が比率を保ったまま縮む
- 確認日は表の中で直接入力でき、隣の **本日反映** で今日の日付が入る。14日を超えると欄が琥珀色に
- 「商品」列の **N 件表示** で行を展開すると、既存の商品だけが表で並ぶ（追加日 / 画像 / 商品名 / 商品URL / 編集 / 確認 / 買付 / 操作）
- **画像をクリックすると拡大表示**。AmazonやRakutenのサムネURLは大きいサイズに組み立て直してから出す。商品名と「商品ページを開く」リンクも一緒に出る。Esc・背景クリック・✕で閉じる。一覧のアイキャッチ画像も同じように開ける
- 商品行の右には状態のドロップダウンが2つ。**確認**（確認前 / 確認後 / スキップ）と **買付**（買付前 / 買付済 / スキップ）。選んだ瞬間に保存される
- 「商品追加」列の **＋ 商品** を押すと、表の1行目に空の入力行が現れてURL欄にカーソルが入る。Enter（または「追加」）で積み上がり、また空行に戻るので連続投入できる
- 商品テーブル右上の **✕ 閉じる** で、その行の商品欄をたたむ
- 商品行の **編集**（オレンジ）でその場で編集。押すと行が入力欄になり、同じ位置が緑の **保存** に変わる（Enterで保存、Escでやめる）
- 編集モーダルは左にアイキャッチ画像、右に各項目（上段に 区分 / 大カテゴリ / 最終確認日、その下に ジャンル名 → URL → 確認内容）、下に追加済みの商品一覧
- **商品URLを入れるだけで画像が自動で入る**。「チェックした商品」に商品URLを入れて追加/編集すると、追加自体はその場で完了して、画像は裏で取りにいく（画像欄が `取得中` になり、取れたらその行だけ差し替わる）。待たされないので、続けて次の商品URLを入れられる。画像欄が空のとき、次の順で拾う
  1. **Amazon** — URL内のASINから、アソシエイトのAsinImageウィジェットと旧来の画像パターンを候補にして、実際に読めたものを採用（⚙️設定にアソシエイトタグを入れると通りやすい）
  2. **楽天** — `item.rakuten.co.jp/{店舗}/{商品番号}/` から itemCode を作り、楽天ウェブサービスの商品検索APIをJSONPで呼ぶ（⚙️設定にアプリID・アクセスキーが要る）
  3. **メタ情報サービス** — microlink にURLを渡して画像URLをもらう
  4. **中継サービス** — ページのHTMLを取って、商品画像や `og:image` / `twitter:image` を拾う（6つを順に試す）。
     Amazonは `hiRes` / `data-old-hires` に加えて、ページ中の `images/I/…` を全部拾い、
     画像IDから大きいサイズのURLを組み立て直して大きい順に試す（サムネやアイコンを掴まないため）

  AmazonのURLは 4 → 3 の順で試す（ページから読むほうが当たるため）。
  どの経路でも、サービス側の既定ロゴ・`no-image`・SVG などは商品画像ではないものとして捨てる

  AmazonのURLは `https://www.amazon.co.jp/dp/{ASIN}` の短い形に直してから照会する。
  画像が入らなかった商品はサムネが `↻` になり、押すともう一度取りにいく（既定で複数の中継先を順に試す。⚙️設定で変更・無効化できる）

  うまく入らないときは ⚙️設定 の **画像取得テスト** に商品URLを入れて「実行」すると、どの段階で止まっているかが出る

  どれも「実際に画像として読めたか」を確認してから採用するので、壊れたURLが入ることはない。手で貼りたいときは今まで通り画像欄に直接URLを入れればよい
- タブごとの検索とカテゴリ絞り込み
- **自動保存**。変更してから約4秒（触り続けていても1分に1回）で `data/products.json` にコミットされる。タブを閉じる・裏に回すときにも保存する。手動の「💾 保存」（`Cmd/Ctrl + S`）も今まで通り使える
  - ヘッダーの表示が `● 未保存（まもなく保存）` → `⟳ 保存中…` → `✓ HH:MM 保存済み` と変わる
  - 失敗したら `⚠ 保存できず` になり、30秒おきに5回まで自動で再試行する。クリックすればその場で再試行
  - 別端末が先に保存していた（409）ときは、最新のshaを取り直して1度だけ自動でやり直す
  - ⚙️設定の「自動保存する」を外せば、これまで通り手動保存だけになる
  - **起動時は必ずGitHubの最新と突き合わせてから保存を解禁する。** この端末のブラウザに残っている
    内容とGitHub側の `updatedAt` を比べて、新しいほうを採用する。突き合わせが終わるまでは
    自動保存も手動保存も走らないので、しばらく開いていなかった端末が他端末の変更を消すことはない
  - GitHub側より件数が半分以下に減る保存は自動では行わない。意図した削除なら「💾 保存」を押すと
    確認のうえで上書きできる

編集内容はブラウザの localStorage にも自動保存されるので、保存し忘れてタブを閉じても復元される
（ヘッダーに `● 未保存` が出ていれば未コミット）。

セットアップは [SETUP.md](SETUP.md) を参照。

## データ形式

```jsonc
{
  "version": 3,
  "updatedAt": "ISO8601",
  "sections": {
    "amazon":   { "items": [ /* 下記の共通形式 */ ] },
    "rakuten":  { "items": [ /* 同上 */ ] },
    "products": { "items": [ /* 同上 */ ] }
  }
}

// 3タブ共通のアイテム
{
  "id": "itm_xxxx",
  "name": "名称",              // 必須（型番商品なら「型番 商品名」）
  "url": "https://...",        // 型番商品タブのURL
  "urlAmazon": "https://...",  // Amazon側のURL（amazon基準 / 楽天基準）
  "urlRakuten": "https://...", // 楽天側のURL（amazon基準 / 楽天基準）
  "image": "https://…/eye.jpg", // アイキャッチ画像
  "category": "カテゴリ",
  "checkNote": "確認内容",
  "checkedAt": "2026-08-19",   // 最終確認日 (YYYY-MM-DD)
  "picks": [                   // 関連URL・チェックした商品
    { "id": "pk_xxxx", "addedAt": "2026-08-19", "image": "", "title": "商品名", "url": "https://...",
      "check": "before|after|skip", "buy": "before|done|skip" }
  ],
  "createdAt": "ISO8601",
  "updatedAt": "ISO8601"
}
```

旧形式（v1の `items` 直下、v2の `model` + `links[]`）は読み込み時に自動で移行される。
型番と商品名は `name` にまとめられ、2本目以降のURLは `picks` に移る。

`links[].type` は `rakuten` / `rakuten_rank` / `amazon` / `amazon_rank` / `yahoo` /
`mercari` / `alibaba` / `taobao` / `official` / `other`。

旧形式（`items` が直下にある v1）のJSONを読み込んだ場合は、自動的に `sections.products` に移行される。
